Engine Architecture

How the Detection Pipeline Operates

Multi-layered client-safe machine learning converting raw uniform resource locators into deterministic cyber risk verdicts in milliseconds.

01

URL Canonicalization

Normalizes bare domains and parses root hosts, top-level domains, subdomains, and query parameters without making network requests.

02

Lexical Feature Extraction

Extracts 22 quantitative indicators including digit ratios, character continuation rate, percent-encoding, and unigram probabilities.

03

Random Forest Ensemble

Feeds extracted features through an ensemble of 100 decorrelated decision trees trained on 235,000+ real-world URLs.

04

Calibrated Risk Verdict

Calculates posterior class probabilities, generates explainable feature cards, and delivers instant threat classification.

Threat Intelligence

Anatomy of Phishing Indicators

Key structural patterns exploited by adversaries and how our model discriminates them.

Direct IP Domain Usage

Phishing campaigns frequently host landing pages on raw IP addresses (e.g. http://192.168.1.1/...) to evade domain registration audits and reputation filters.

Hex & Character Obfuscation

Adversaries use percent-encoding (%20, %2e) and unusual escapes to conceal malicious paths and bypass simple string pattern matchers.

Excessive Digit & Special Char Ratios

Phishing URLs display abnormally elevated proportions of digits, hyphens, and delimiters in the domain name to simulate session hashes or brand spoofs.

Subdomain Nesting

Cybercriminals stack multiple subdomains (e.g. paypal.com.verify-user.online) to deceive mobile users who only see the start of the host name.
